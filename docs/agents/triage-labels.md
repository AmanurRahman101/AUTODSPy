# Triage labels

Canonical roles map directly to these tracker labels:

- needs-triage: maintainer needs to evaluate the issue.
- needs-info: waiting on the reporter for more information.
- ready-for-agent: fully specified and ready for an agent.
- ready-for-human: requires human implementation.
- wontfix: will not be actioned.

Use these exact strings when a skill refers to a triage role.
Edit this mapping if the tracker vocabulary changes.
